This Business Message Standard (BMS) publication package provides the
necessary information to implement this message as part of the GS1 System.  
The information contained within this package is a direct result of the 
work conducted by the Global Standards Management Process’ Business and 
Technical Requirements Groups. 

The contents of this package is a single source collection of material 
that will provide the necessary basics to understand and implement this 
GS1 Business Message Standard (BMS). 

The following elements are available:

1. BMS Document:
   Defines the business solution of the BMS (Requires Adobe Acrobat Reader)

2. Technical Solution Implementers Packet:
   Contains the XSD files required for implementation
